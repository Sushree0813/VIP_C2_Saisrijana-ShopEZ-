# ShopEZ - E-Commerce Application

## Project Overview

ShopEZ is a MERN Stack based E-Commerce Application developed to provide a seamless online shopping experience. The application allows users to browse products, add items to the cart, place orders, and manage their purchases efficiently.

## Technologies Used

* MongoDB
* Express.js
* React.js
* Node.js
* JWT Authentication

## Features

* User Registration and Login
* Product Browsing
* Product Details View
* Add to Cart Functionality
* Order Management
* Secure Authentication
* Responsive User Interface

## Project Structure

* MERN Phase Wise
* Project Documentation
* Screenshots
* shopEZ/client
* shopEZ/server

## Installation

1. Clone the repository.
2. Install dependencies using npm install.
3. Configure MongoDB connection.
4. Start the client and server applications.
